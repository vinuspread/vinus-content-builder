# UI 리디자인 설계

## 개요

Linear 이슈 목록 + Buffer 콘텐츠 관리 UI를 참고한 전면 재설계. 핵심 원칙은 **점진적 노출(Progressive Disclosure)** + **행 기반 목록(Row-based List)**. 기본 상태에서 최소 정보만 표시하고, 필요할 때만 액션을 드러낸다.

**디자인 기준:**
- Notion/Linear 스타일 — 미니멀, 여백 충분, 텍스트 중심
- 테두리 최소화 — 구분은 여백과 배경색으로
- 액션은 오른쪽 정렬, 보조 액션은 숨김 처리
- 모든 목록은 행(row) 기반

---

## 1. 수집콘텐츠 페이지

### 변경 전 문제
- 썸네일 + 배지 + 제목 + 캡션 + 유형 드롭다운 + 링크 + 버튼 = 아이템당 정보 과부하
- 헤더에 버튼 3개 + 필터 3개 + 상태 메시지 혼재
- 수집 중 진행 바가 헤더를 밀어냄

### 변경 후 구조

**헤더 (2요소만)**
```
수집콘텐츠  30개    [수집 실행]
마지막 수집: 2026.05.19 11:24
```
- "미분류 자동 분류" 버튼 헤더에서 제거 → 수집 버튼 옆 `···` 메뉴 안으로 이동 (기능은 유지)
- 수집 중 진행 표시는 버튼 아래 inline progress bar (헤더 레이아웃 밀지 않음)

**필터 바 (1줄)**
```
[Instagram ▾]  [유형 ▾]  [정렬: 반응 수 ▾]
```
- 기존 3개 select 그대로 유지, 시각적 정리만

**목록 행**
```
[●] [Instagram]  바이너스리거    브랜드가 컬러를 잘못 쓰는 이유         [카드뉴스 생성]
[●] [RSS]        디자인매거진    왜 AI 디자인 툴이 전문가를 대체 못하나  ✓ 생성완료
```

- 썸네일 제거
- 제목 1줄 (line-clamp-1), 캡션 미표시
- 유형 드롭다운 행에서 제거 → 상세 또는 생성 후 수정
- "생성완료" 항목: 텍스트 흐리게(muted), 버튼 "생성완료" 비활성
- "카드뉴스 생성" 버튼: 항상 우측 고정, 생성 중엔 `생성 중... 23초`
- 행 클릭 시 원본 URL 이동 없음 (원본 링크는 버튼으로만)
- 좋아요 수: 제목 옆 작은 텍스트로 표시 또는 제거
- 원본 링크: 행 우측 끝 `↗` 아이콘 버튼으로 표시 (새 탭 열기)

### 제거 항목
- 썸네일 이미지
- 캡션 미리보기 2줄
- 인라인 유형 드롭다운 (행에서 제거)
- "미분류 자동 분류" 버튼 (수집 API에서 자동 처리)

### 수집 중 상태
```
수집콘텐츠  30개    [수집 중... 12초]
[████████░░░░░░░░░░░░] 37%
```
- 진행 바가 헤더 바로 아래에 표시, 목록은 그대로 유지

## 2. 카드뉴스목록 페이지

### 변경 전 문제
- "+ 직접 입력" 폼이 목록 위를 차지하며 레이아웃을 밀어냄
- 배지 3종(유형, 자체콘텐츠, 업로드완료)이 한 행에 혼재
- 진행 바 + 단계 메시지가 폼 내부에 있어 공간 차지

### 변경 후 구조

**헤더**
```
카드뉴스목록                    [+ 직접 입력]
```

**직접 입력 폼 (토글, 목록 위에 삽입)**
```
┌─────────────────────────────────────────┐
│ 주제 *  [_________________________________]│
│ 내용    [_________________________________]│
│         [_________________________________]│
│                         [카드뉴스 생성]   │
│ [████████████░░░░░░] 생성 중... 23초     │  ← 생성 중에만 표시
└─────────────────────────────────────────┘
```

**목록 행**
```
브랜드가 컬러를 잘못 쓰는 이유        브랜딩    05.19
자체  AI 디자인 트렌드 2026            미분류    05.18
스타트업이 놓치는 로고 실수            브랜딩    05.17 ✓
```

- 유형: 우측 작은 텍스트 (badge 제거, 텍스트로)
- 자체콘텐츠: 행 앞 `자체` 작은 레이블 (파란색 텍스트)
- 업로드완료: 행 우측 ✓ 아이콘 (badge 제거)
- 날짜: 우측 정렬

## 3. 카드뉴스 상세 페이지

### 변경 전 문제
- 카드 6장 + 인스타그램 본문 + 해시태그 + 피드백 카드 + 업로드 카드 = 매우 긴 스크롤
- 액션(피드백, 저장)이 스크롤 맨 아래에 있어 접근 불편
- 삭제/복사 버튼이 맨 위에만 있음

### 변경 후 구조: 2컬럼 레이아웃

```
← 목록                  브랜딩  자체콘텐츠          [복사] [삭제]

브랜드가 컬러를 잘못 쓰는 이유
중소기업 실무자가 놓치는 컬러 전략

─────────────────────────────────┬──────────────────
                                 │
  카드뉴스 · 6장                 │  콘텐츠 유형
                                 │  [브랜딩         ▾]
  1 · 표지                       │
  컬러가 브랜드를 망친다          │  ─────────────────
  본문...                        │  업로드
                                 │  □ SNS 업로드 완료
  2 · 문제제기                   │  [인스타그램 URL  ]
  ...                            │  [저장]
                                 │
  3 · 원인분석                   │  ─────────────────
  ...                            │  피드백 재생성
                                 │  [________________]
  인스타그램 본문                 │  [________________]
  ...                            │  [재생성]
                                 │
  해시태그                       │
  #브랜딩 #디자인 ...            │
─────────────────────────────────┴──────────────────
```

- **왼쪽 (2/3):** 카드 원고 + 인스타그램 본문 + 해시태그 (스크롤)
- **오른쪽 (1/3):** 유형 선택 + 업로드 체크 + 피드백 (sticky, 고정)
- 카드별 expertView/practical/characterMent는 접힌 상태로 시작 (클릭 시 펼침)

### 카드 아이템 구조
```
1 · 표지
헤드라인 텍스트

본문 텍스트...

▶ 전문가 관점  (클릭 시 펼침)
▶ 실무 적용    (클릭 시 펼침)
▶ 캐릭터 멘트  (클릭 시 펼침)
```

## 4. 설정 페이지

### 변경 후 구조

상단 탭 → **좌측 사이드바** 메뉴로 변경

```
┌──────────┬─────────────────────────────────┐
│          │                                 │
│ 콘텐츠   │  콘텐츠 유형                    │
│ 유형     │  ─────────────────────────────  │
│          │  □  브랜딩          목표 [30] %  │
│ Instagram│  □  마케팅          목표 [20] %  │
│ 계정     │  ...                            │
│          │                    [저장]        │
│ 해시태그 │                                 │
│          │                                 │
│ RSS 소스 │                                 │
│          │                                 │
│ 수집 필터│                                 │
│          │                                 │
└──────────┴─────────────────────────────────┘
```

- 사이드바 너비: 160px 고정
- 현재 선택된 메뉴: 배경 강조

## 제거/통합 항목 요약

| 항목 | 처리 |
|------|------|
| 수집콘텐츠 썸네일 | 제거 |
| 수집콘텐츠 캡션 미리보기 | 제거 |
| 수집콘텐츠 인라인 유형 드롭다운 | 제거 |
| "미분류 자동 분류" 버튼 | 헤더에서 제거 → `···` 메뉴로 이동 |
| 카드뉴스목록 Badge 3종 | 텍스트/아이콘으로 경량화 |
| 카드뉴스 상세 긴 스크롤 | 2컬럼으로 분리 |
| 카드뉴스 상세 하단 카드들 | sticky 우측 패널로 이동 |
| 설정 상단 탭 | 좌측 사이드바로 변경 |
| 카드별 보조 정보 (expertView 등) | 접힌 상태로 시작 |
