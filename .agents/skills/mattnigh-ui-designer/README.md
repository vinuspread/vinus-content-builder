# Skills Collection

A large, growing corpus of skill write-ups lives in [collection/](collection/). Each file is indexed into a searchable dataset hosted via GitHub Pages.

## Web explorer (GitHub Pages)

- Live site: https://mattnigh.github.io/skills_collection/
- Source: [docs/index.html](docs/index.html) with data at [docs/data/analysis.json](docs/data/analysis.json)
- Features: fast search, repo/language filters, code-only toggle, links to rendered, raw, and upstream sources.
